# 智能美食推荐系统 API 接口文档

> 文档位置：项目根目录（与 `CLAUDE.md` 同级）
> 基础路径：`http://localhost:8080`

---

## 1. 统一说明

### 1.1 认证方式

除登录/注册外，接口需要在 Header 携带 JWT：

- Header: `Authorization: Bearer <token>`

当前拦截规则：

- 需要认证：`/api/**`、`/ai/**`
- 放行：
  - `POST /api/user/login`
  - `POST /api/user/register`

---

### 1.2 统一返回格式

所有接口返回 `CommonResult<T>`：

```json
{
  "code": 200,
  "msg": "操作成功~",
  "data": {}
}
```

常用状态码：

- `200` 成功
- `400` 请求参数错误
- `401` 未登录或登录失效
- `403` 无权限
- `404` 资源不存在
- `500` 系统异常

---

### 1.3 全局异常返回

- `MethodArgumentNotValidException` / `ConstraintViolationException` -> `400`
- `UnauthorizedException` -> `401`
- `BusinessException` -> 业务定义状态码
- 其他异常 -> `500`

## 2. 用户模块 `UserController`

前缀：`/api/user`

### 2.1 用户注册

- 方法：`POST`
- 路径：`/api/user/register`
- 鉴权：否

请求体：

```json
{
  "username": "zhangsan",
  "password": "123456",
  "phone": "13800138000",
  "nickname": "张三"
}
```

参数约束：

- `username`：不能为空
- `password`：不能为空
- `phone`：手机号格式 `^1[3-9]\d{9}$`

响应：`CommonResult<Void>`

---

### 2.2 用户登录

- 方法：`POST`
- 路径：`/api/user/login`
- 鉴权：否

请求体：

```json
{
  "username": "zhangsan",
  "password": "123456"
}
```

响应：`CommonResult<String>`

- `data` 为 JWT token

---

### 2.3 获取当前用户信息

- 方法：`GET`
- 路径：`/api/user/info`
- 鉴权：是

响应：`CommonResult<UserVO>`

```json
{
  "id": 1,
  "username": "zhangsan",
  "phone": "13800138000",
  "nickname": "张三",
  "avatar": "...",
  "gender": 1,
  "birthday": "1995-06-15"
}
```

## 3. 餐厅模块 `RestaurantController`

前缀：`/api/restaurant`

### 3.1 餐厅分页查询

- 方法：`GET`
- 路径：`/api/restaurant/list`
- 鉴权：是

Query 参数：

- `current`：页码（默认 `1`，且 `>=1`）
- `size`：每页条数（默认 `10`，范围 `1~100`）
- `category`：菜系（可选）
- `minPrice`：最低人均（可选）
- `maxPrice`：最高人均（可选）
- `minRating`：最低评分（可选）

响应：`CommonResult<Page<RestaurantVO>>`

---

### 3.2 餐厅详情

- 方法：`GET`
- 路径：`/api/restaurant/{id}`
- 鉴权：是

响应：`CommonResult<RestaurantVO>`

`RestaurantVO` 关键字段：

- 基础信息：`id/name/category/address/avgPrice/rating/...`
- `dishes`: 菜品列表
- `aiSummary`: AI 口碑摘要（当前为摘要文本）

---

### 3.3 新增餐厅（预留）

- 方法：`POST`
- 路径：`/api/restaurant/add`
- 鉴权：是
- 当前状态：未实现（返回错误）

### 3.4 修改餐厅（预留）

- 方法：`PUT`
- 路径：`/api/restaurant/update`
- 鉴权：是
- 当前状态：未实现（返回错误）

## 4. 订单模块 `OrderController`

前缀：`/api/order`

### 4.1 创建订单

- 方法：`POST`
- 路径：`/api/order`
- 鉴权：是

请求体：

```json
{
  "restaurantId": 1,
  "reservationTime": "2026-04-10T18:30:00",
  "peopleCount": 4,
  "contactName": "张三",
  "contactPhone": "13800138000",
  "specialRequest": "靠窗"
}
```

参数约束：

- `restaurantId` 非空
- `reservationTime` 非空且必须是未来时间
- `peopleCount` 范围 `1~50`
- `contactName` 非空
- `contactPhone` 非空

响应：`CommonResult<Void>`

---

### 4.2 订单分页查询

- 方法：`GET`
- 路径：`/api/order/list`
- 鉴权：是

Query 参数：

- `current`：页码（默认 `1`）
- `pageSize`：每页条数（默认 `10`）
- `status`：订单状态（可选）
  - `0` 待确认
  - `1` 已确认
  - `2` 已完成
  - `3` 已取消

响应：`CommonResult<Page<OrderVO>>`

---

### 4.3 订单详情

- 方法：`GET`
- 路径：`/api/order/{orderNo}`
- 鉴权：是

响应：`CommonResult<OrderVO>`

---

### 4.4 取消订单

- 方法：`PUT`
- 路径：`/api/order/{orderNo}/cancel`
- 鉴权：是

仅允许取消 `待确认` 订单。

响应：`CommonResult<Void>`

---

## 5. 评价模块 `ReviewController`

前缀：`/api/review`

### 5.1 发表评价

- 方法：`POST`
- 路径：`/api/review`
- 鉴权：是

请求体：

```json
{
  "orderId": 1001,
  "rating": 5,
  "tasteRating": 5,
  "environmentRating": 4,
  "serviceRating": 5,
  "content": "菜品很新鲜，服务很好",
  "images": [
    "https://xxx/a.jpg",
    "https://xxx/b.jpg"
  ]
}
```

参数约束：

- `orderId` 非空
- `rating` 范围 `1~5`
- `tasteRating/environmentRating/serviceRating` 范围 `1~5`（可选）
- `content` 长度最大 `500`

响应：`CommonResult<Void>`

---

### 5.2 审核通过（管理端预留）

- 方法：`PUT`
- 路径：`/api/review/{id}/approve`
- 鉴权：是
- 备注：当前未做管理员权限隔离，后续需补 RBAC

### 5.3 审核拒绝（管理端预留）

- 方法：`PUT`
- 路径：`/api/review/{id}/reject`
- 鉴权：是
- 备注：当前未做管理员权限隔离，后续需补 RBAC

---

### 5.4 查询餐厅评价列表

- 方法：`GET`
- 路径：`/api/review/restaurant`
- 鉴权：是

Query 参数：

- `restaurantId`（必填）
- `current`（默认 `1`）
- `pageSize`（默认 `10`，最大 `100`）
- `rating`（可选）

响应：`CommonResult<Page<ReviewVO>>`

---

### 5.5 查询我的评价列表

- 方法：`GET`
- 路径：`/api/review/myReviews`
- 鉴权：是

Query 参数：

- `current`（默认 `1`）
- `pageSize`（默认 `10`，范围 `1~100`）

响应：`CommonResult<Page<MyReviewVO>>`

---

### 5.6 查询我的评价详情

- 方法：`GET`
- 路径：`/api/review/myReviews/{id}`
- 鉴权：是

响应：`CommonResult<MyReviewVO>`

---

### 5.7 删除我的评价

- 方法：`DELETE`
- 路径：`/api/review/myReviews/{id}`
- 鉴权：是

响应：`CommonResult<Void>`

## 6. AI 模块 `ChatController`

前缀：`/ai`

### 6.1 AI 对话

- 方法：`GET`
- 路径：`/ai/chat`
- 鉴权：是（当前拦截 `/ai/**`）

Query 参数：

- `message`：用户问题（必填）

说明：

- 会话 `memoryId` 由后端自动使用当前登录用户 ID
- 返回为非流式 `CommonResult<String>`

示例：

`GET /ai/chat?message=推荐一家适合家庭聚餐的川菜馆`

## 8. 测试调用建议

### 8.1 推荐测试顺序

1. `POST /api/user/register`
2. `POST /api/user/login`（拿 token）
3. 之后所有请求带 `Authorization: Bearer <token>`

### 8.2 Postman 变量建议

- `baseUrl` = `http://localhost:8080`
- `token` = 登录返回 `data`

Header 统一配置：

- `Authorization: Bearer {{token}}`
